# HomeMenu

HomeMenu — домашнее меню для локальной сети. Оно показывает, что есть в наличии и где это хранится. Остатки общие для всех устройств. Приложение работает на Go и SQLite, а интерфейс поставляется вместе с сервером.

## Развёртывание в Docker

Нужны Docker Engine и Docker Compose. На сервере с OpenMediaVault, в том числе WD Sentinel DX4000, выполняйте команды по SSH из каталога проекта.

```sh
docker compose up -d --build
docker compose ps
```

По умолчанию приложение публикуется на порту **5000**. На сервере откройте [меню](http://localhost:5000/) или [админпанель](http://localhost:5000/admin). На другом устройстве в той же сети замените `localhost` на LAN-адрес сервера, например `http://192.168.0.112:5000/`.

Админпанель доступна без авторизации. Разворачивайте приложение в доверенной локальной сети и не публикуйте порт 5000 в интернете.

### Настройки запуска

При необходимости создайте рядом с `compose.yaml` локальный файл `.env`. Например, для первого запуска с пробным меню и QR-кодами на локальный адрес:

```dotenv
SEED_DEMO=1
HOMEMENU_PUBLIC_URL=http://192.168.0.112:5000/
```

| Переменная | Назначение |
| --- | --- |
| `SEED_DEMO` | При значении `1` заполняет пустой каталог тестовыми разделами, позициями, тегами и местами хранения. Существующие записи не меняются. По умолчанию `0`. |
| `HOMEMENU_PUBLIC_URL` | Адрес, который кодируется в QR-коде. Укажите фактический адрес сервера в LAN, если QR-код должен работать даже при открытии админпанели через `localhost`. Без переменной используется адрес запроса к приложению. |

Применить изменения конфигурации или обновить приложение после обновления исходников:

```sh
docker compose up -d --build
docker compose logs --tail=100 homemenu
```

### Данные и резервное копирование

Именованный том `homemenu-data` монтируется в `/data`. В нём хранятся SQLite-база `menu.sqlite`, изображения в `photos/` и загруженные шрифты в `fonts/`. Обычное пересоздание контейнера сохраняет том. Команда `docker compose down -v` удаляет его вместе с данными.

Для согласованной копии остановите приложение на время архивации:

```sh
docker compose stop homemenu
docker compose run --rm --no-deps -T --entrypoint tar homemenu -czf - -C /data . > homemenu-backup.tar.gz
docker compose start homemenu
```

Для восстановления на другом сервере подготовьте сборку, распакуйте архив в новый пустой том приложения и запустите сервис:

```sh
docker compose build homemenu
docker compose run --rm --no-deps -T --entrypoint tar homemenu -xzf - -C /data < homemenu-backup.tar.gz
docker compose up -d
```

## Просмотр меню

- **Главная** показывает доступные позиции, сгруппированные по разделам. Разделы открываются из панели навигации, на телефоне — через бургер-меню.
- **Теги** фильтруют позиции по правилу «хотя бы один выбранный тег». После сброса видны и позиции без тегов. Переключатель «Карточки / Список» запоминает выбранный вид в браузере.
- **Карточка позиции** показывает фото, место хранения, описание, теги и остаток. Длинное описание можно раскрыть через «Подробнее». Свайпы влево и вправо или стрелки на ПК листают позиции в текущем порядке с учётом фильтра.
- **Взять** сразу списывает одну штуку. Позиции с нулевым остатком скрываются из меню, но их карточки доступны по прямой ссылке.
- **Корзина** хранится в текущем браузере. Она не резервирует продукты. Кнопка «Взять всё» списывает всю корзину одной операцией. Если какой-либо позиции не хватает, остатки не меняются, а корзина остаётся для корректировки.

## Админпанель

На ПК ссылка **«Админпанель»** находится в правой части шапки, на телефоне — внизу бургер-меню. Прямой путь — `/admin`.

| Вкладка | Что можно сделать |
| --- | --- |
| Позиции | Добавить или изменить блюдо или продукт, указать раздел, остаток, порядок, теги, место хранения, описание и фото. Кнопки «−» и «+» в списке меняют остаток на одну штуку. |
| Разделы | Создать разделы и настроить порядок вывода. Меньшее значение показывается раньше. Порядок позиций внутри раздела настраивается так же. |
| Теги и места хранения | Вести справочники для фильтрации и указания расположения продуктов. |
| Главная | Загрузить изображение и задать подпись над общим меню. |
| Оформление | Настроить название меню, подпись о фотографиях, цвета светлой и тёмной темы и шрифт. Можно выбрать системный шрифт, Georgia или моноширинный, либо загрузить WOFF2, WOFF, TTF или OTF до 8 МиБ. |
| Подключение | Сгенерировать QR-код для главной или конкретного раздела. |
| Заполнение из файла | Загрузить JSON-файл или вставить JSON в текстовое окно. Полная схема с примером доступна под пунктом «Формат JSON и пример». |

### Импорт JSON

Поддерживаются массивы `sections`, `tags`, `places` и `items`. Можно передавать только те массивы, которые нужно обновить. Минимальный пример с новой позицией:

```json
{
  "sections": [{"name": "Напитки"}],
  "tags": [{"name": "Охлаждённое"}],
  "places": [{"name": "Холодильник"}],
  "items": [
    {
      "name": "Лимонад",
      "section": "Напитки",
      "quantity": 4,
      "tags": ["Охлаждённое"],
      "place": "Холодильник"
    }
  ]
}
```

Импорт обновляет записи с совпадающими названиями. Регистр и крайние пробелы игнорируются, а название позиции проверяется по всему меню. Пропущенные поля существующей записи сохраняются. Новая позиция требует `name`, `section` и целого `quantity` от нуля. При ошибке весь импорт отменяется. Максимальный размер JSON — 25 МиБ.

## Локальная разработка

Для запуска без Docker нужны Go, компилятор C для драйвера SQLite и включённый CGO. Сервер слушает порт 5000 и по умолчанию хранит данные в каталоге `data/`. Чтобы использовать другой каталог, передайте `DATA_DIR`.

```sh
CGO_ENABLED=1 go test ./...
CGO_ENABLED=1 SEED_DEMO=1 go run .
```
